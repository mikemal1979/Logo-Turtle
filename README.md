# Logo-Turtle
Version de Logo-Turtle, programacion en modo consola y en modo bloques, con el clasico programa de logo

para funcionar, utiliza un servidor local, ya sea con python o con xampp.
si es python... 
desde la consola, ubica la carpeta del proyecto y ejecuta python -m http.server 8000

Si es xampp...
ubica la carpeta dentro de htdocs

en el navegador localhost:8000/index.html
