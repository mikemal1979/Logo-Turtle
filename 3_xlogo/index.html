Guía Completa de Comandos Logo & Bloques Visuales

Movimiento Básico y Posición
  • ADELANTE n / AV n / FORWARD n
    Mueve la tortuga hacia adelante n pasos.
    Ejemplo: adelante 100 o av 50
  • RETROCEDE n / RE n / BK n / BACKWARD n
    Mueve la tortuga hacia atrás n pasos.
    Ejemplo: retrocede 60 o re 30
  • DERECHA n / GD n / DE n / RIGHT n
    Gira la tortuga a la derecha n grados.
    Ejemplo: derecha 90 o gd 45
  • IZQUIERDA n / GI n / IZ n / LEFT n
    Gira la tortuga a la izquierda n grados.
    Ejemplo: izquierda 90 o gi 120
  • PONPOS x y / PONXY x y / IR_A x y
    Mueve la tortuga a las coordenadas `X` e `Y` especificadas.
    Ejemplo: ponpos 100 -50
Formas Geométricas y Relleno
  • CIRCULO radio / CIRCLE r
    Dibuja un círculo centrado en la posición actual de la tortuga.
    Ejemplo: circulo 50
  • CIRCULORELLENO radio / PARC 360 r
    Dibuja un círculo completamente relleno con el color actual.
    Ejemplo: circulorelleno 40 o parc 360 40
  • ELIPSE rx ry / ELLIPSE rx ry
    Dibuja una elipse con radio horizontal rx y radio vertical ry.
    Ejemplo: elipse 100 50
  • ELIPSERELLENA rx ry / PALE rx ry 360
    Dibuja una elipse completamente rellena.
    Ejemplo: elipserellena 80 40
  • PONCOLORRELLENO color / SETFLOODCOLOR color
    Establece el color que usará la herramienta de relleno.
    Ejemplo: poncolorrelleno rojo
  • RELLENA / FILL
    Rellena el área delimitada o figura cerrada en la posición actual de la tortuga.
    Ejemplo: subelapiz av 20 rellena
Control del Lápiz y Colores
  • SUBELAPIZ / SP / SL / PENUP
    Levanta el lápiz para moverse sin dejar rastro ni dibujar.
    Ejemplo: subelapiz av 50 bajalapiz
  • BAJALAPIZ / CP / BL / LAPIZ / PENDOWN
    Apoya el lápiz para volver a dibujar líneas al desplazarse.
  • BORRA / PE / BORRADOR
    Lápiz Borrador: Cambia al modo goma de borrar. Al desplazarte sobre líneas dibujadas, estas desaparecerán.
    Ejemplo: borra re 100 lapiz
  • PONCOLOR color / PC n
    Cambia el color del lápiz. Acepta nombres (verde, rojo, cian...), códigos `#hex` o los números de la Paleta Oficial (0 a 15):
    0: Negro 1: Azul 2: Verde 3: Cian 4: Rojo 5: Rosa 6: Amarillo 7: Blanco 8: Naranja 9: Violeta 10: Marrón 11: Azul C. 12: V. Lima 13: Turquesa 14: Coral 15: Gris
    Ejemplo: pc verde o pc 4 o pc 13
  • PONGROSOR n / PG n / PONANCHO n
    Establece el grosor de la línea en píxeles. (Ejemplo: pongrosor 5).
Pantalla y Control Visual
  • BORRAPANTALLA / BP / LP / LIMPIAR
    Borra todos los trazos del lienzo y restablece la vista.
  • ORIGEN / HOME / INICIO / CENTRAR
    Envia la tortuga de regreso al centro del lienzo `(0, 0)`.
  • OCULTARTORTUGA / OT / HIDETURTLE
    Hace invisible el icono de la tortuga para ver solo el dibujo final.
  • MOSTRARTORTUGA / MT / SHOWTURTLE
    Vuelve a hacer visible el icono de la tortuga.
Control de Flujo (Bucles y Condicionales)
  • REPITE / REPETIR n [ instrucciones ]
    Repite las instrucciones entre corchetes n veces consecutivas.
    Cuadrado: repetir 4 [ adelante 100 derecha 90 ]
    Estrella: repite 5 [ av 120 gd 144 ]
  • MIENTRAS condición [ instrucciones ]
    Repite las instrucciones mientras la condición sea verdadera.
    Ejemplo: mientras :i < 5 [ av 10 haz "i :i + 1 ]
  • HAZ [ instrucciones ] MIENTRAS condición
    Ejecuta las instrucciones al menos una vez y las repite mientras la condición sea verdadera.
    Ejemplo: haz [ av 10 haz "i :i + 1 ] mientras :i < 5
  • SI condición [ instrucciones ]
    Ejecuta las instrucciones entre corchetes solo si la condición se cumple.
    Ejemplo: si :i = 5 [ pc rojo av 50 ]
Variables e Interacción
  • HAZ "variable valor / MAKE "var val
    Crea o actualiza el valor de una variable.
    Ejemplo: haz "pasos 100 av :pasos
  • PREGUNTA "mensaje / ASK "mensaje
    Solicita un valor al usuario y guarda el resultado en :respuesta.
    Ejemplo: pregunta "¿Cuántos lados?" repite :respuesta [ av 50 gd 360 / :respuesta ]
  • ESCRIBE texto / IMPRIME texto / ETIQUETA texto
    Imprime un texto o el resultado de una expresión en la consola de comandos.
    Ejemplo: escribe :respuesta
Procedimientos (Funciones)
  • PARA nombre :param1 :param2 ... [instrucciones] FIN
    Define una nueva función reutilizable con variables opcionales. 
    PARA CUADRADO_VARIABLE :LADO
  REPITE 4 [ADELANTE :LADO DERECHA 90]
FIN
